// ARCHITECTURE & FEATURES

Engineered for Homelab & Enterprise Performance

How the multi-stage hardware pipeline analyzes, transcodes, and verifies each video stream.

⚡

Universal GPU Auto-Detection

Intelligently probes for NVIDIA NVENC (hevc_nvenc), Intel QuickSync (hevc_qsv), Apple Silicon VideoToolbox, or VAAPI. Falls back gracefully to multi-threaded CPU only if no hardware ASIC is present.

🛡️

Atomic Staging Safeguard

Videos transcode into a hidden staging file (.filename.transcoding.mp4). The source file is never touched or removed until FFmpeg exits with code 0 and byte validation succeeds.

🔍

Intelligent Stream Inspection

Uses ffprobe to analyze video tracks. Files already encoded in high-efficiency H.265 in an MP4 container are automatically skipped, eliminating redundant compression and generational degradation.

🎬

FastStart Instant Direct Play

Applies -movflags +faststart to relocate the MP4 MOOV atom to the beginning of the file. Enables instantaneous playback in Plex, NovaFlix, Jellyfin, and browsers with zero buffering pauses.

🔊

Audio & Subtitle Passthrough

Streamlines surround and stereo audio into high-bitrate AAC (192kbps) for cross-platform hardware support and preserves embedded timed-text subtitles (mov_text).

📊

Live Telemetry & Delta Metrics

Calculates real-time compression ratios and outputs colorized terminal summaries reporting total scanned items, original vs. new footprint, and net GB storage saved across your drives.

Ready in 30 Seconds

No compilation required. Pure Python 3 and standard FFmpeg hardware encoders.

1. Clone & Run with Hardware Acceleration
# Clone the repository git clone https://github.com/digdast/ffmpeg_convert_h265_mp4.git cd ffmpeg_convert_h265_mp4 # Execute interactive or direct batch run python3 transcode_media.py /path/to/media/library
2. Advanced CLI Options
# Force NVIDIA NVENC with high visual quality (CQ 20) python3 transcode_media.py /data/movies --encoder hevc_nvenc --cq 20 # Dry-run preview without touching files python3 transcode_media.py /data/movies --dry-run # Transcode and clean up original MKV files upon success python3 transcode_media.py /data/downloads --delete-original
