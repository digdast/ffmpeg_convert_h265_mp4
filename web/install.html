Cross-Platform 1-Line Installer & Usage Guide

Deploy transcode-media across Linux, macOS, and Windows in seconds via curl or PowerShell. Complete with automatic hardware GPU detection and safety mechanisms.

1
Quick Install via curl (Recommended)
Installs transcode-media and alias ffmpeg-convert directly to your PATH.
curl -fsSL https://ffmpeg.ertechlab.com/install.sh | bash

Alternative GitHub raw source: curl -fsSL https://raw.githubusercontent.com/digdast/ffmpeg_convert_h265_mp4/main/install.sh | bash

2
System Prerequisites & GPU Drivers
Requires Python 3.9+ and FFmpeg with hardware acceleration support.

Debian / Ubuntu:

sudo apt update && sudo apt install python3 ffmpeg -y

Arch Linux:

sudo pacman -S python ffmpeg

💡 For NVIDIA NVENC acceleration on Linux, ensure the proprietary NVIDIA display driver is loaded (nvidia-smi).

3
Verify Installation
transcode-media --help
1
1-Line Install via Terminal
Supports M1/M2/M3/M4 Apple Silicon and Intel Macs with native VideoToolbox GPU acceleration.
curl -fsSL https://ffmpeg.ertechlab.com/install.sh | bash
2
Homebrew Dependencies
Install FFmpeg built with Apple VideoToolbox hardware encoder support.
brew install python ffmpeg

🍏 Apple VideoToolbox uses dedicated hardware media silicon on M-series chips for ultra-fast, zero-fan-noise transcoding.

3
Verify CLI Availability
transcode-media --help
1
1-Line PowerShell Installation
Runs in standard Windows PowerShell (5.1) or PowerShell Core (7+). No admin rights required.
irm https://ffmpeg.ertechlab.com/install.ps1 | iex

Alternative GitHub raw source: irm https://raw.githubusercontent.com/digdast/ffmpeg_convert_h265_mp4/main/install.ps1 | iex

2
Prerequisites via Windows Package Manager (winget)
If Python or FFmpeg are not already in your Windows PATH, install both with a single command:
winget install Python.Python.3.12 Gyan.FFmpeg

💡 Gyan.FFmpeg includes full NVIDIA NVENC and Intel QuickSync hardware codecs out of the box.

3
Instant Global Execution
Both transcode-media and ffmpeg-convert are available in CMD and PowerShell:
transcode-media "D:\Media\Movies" --dry-run
1
Docker with NVIDIA GPU Passthrough
Run batch transcoding in an isolated container mounting your host media shares:
docker run --rm -it --gpus all -v /data/media:/media python:3.11-slim bash -c "apt update && apt install -y ffmpeg curl && curl -fsSL https://ffmpeg.ertechlab.com/install.sh | bash && transcode-media /media"
2
Kubernetes CronJob / Worker Integration
Deploy directly onto your K3s / K8s cluster alongside NFS persistent volumes.
kubectl apply -f https://ffmpeg.ertechlab.com/k8s/k8s-manifest.yaml

📖 Practical Transcoding Recipes

Common commands and workflows for homelab automation, Plex, and media servers.

🔍 1. Safe Dry-Run (Preview Candidates)

Scans your directory recursively, probes all media files with ffprobe, and prints candidate count and size without encoding anything.

transcode-media /media/downloads --dry-run

⚡ 2. Replace Originals (In-Place Transcode)

Automatically replaces the original MKV/AVI/MOV with the modern H.265 MP4 upon successful atomic verification.

transcode-media /media/movies --delete-original

🎯 3. Archival Ultra-Quality (CQ 19, Slow Preset)

Ideal for 4K UHD or 1080p high-bitrate remuxes where visually lossless fidelity is prioritized over file size.

transcode-media /media/remux --preset p7 --cq 19

⚙️ 4. Explicit Hardware Engine Override

Force a specific hardware encoder instead of relying on automatic detection order.

transcode-media /media/tv --engine nvenc

🎵 5. Audio Passthrough (Copy Existing Tracks)

Bypasses AAC re-encoding and preserves original multichannel DTS-HD / TrueHD / FLAC audio streams.

transcode-media /media/concerts --no-audio-transcode

📁 6. Target Specific File Extensions

Only scan and transcode older legacy containers, skipping existing modern containers.

transcode-media /media/archive --exts .avi .wmv .mov

⚙️ Complete CLI Parameter Reference

All options supported by transcode-media.

Flag / Parameter Type / Choices Default Description
target Path (Positional) Required Directory or individual video file path to scan and transcode.
--engine auto, nvenc, qsv, videotoolbox, vaapi, cpu auto Select hardware GPU encoder engine or fallback to multi-core CPU.
--cq / --crf Integer (0–51) 24 Constant Quality / Rate Factor. Lower value = higher quality and larger file.
--preset String p5 (NVENC) / medium (CPU) Encoding speed/efficiency trade-off preset (e.g. p1-p7, fast, slow).
--delete-original Flag False Delete original source file upon successful atomic completion and verification.
--dry-run Flag False Probe and scan media library without executing any FFmpeg transcode commands.
--no-audio-transcode Flag False Copy all audio streams directly without downmixing/transcoding to AAC stereo.
--audio-bitrate String 192k Target bitrate for transcoded audio tracks (e.g., 128k, 256k, 320k).
--exts List of Strings .mkv .avi .mov .wmv .webm .mp4 Space-separated list of video file extensions to evaluate.
-h, --help Flag — Display the built-in command help menu, version, and exit.
